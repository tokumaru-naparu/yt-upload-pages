# yt-upload

yt-upload は、個人が自分の YouTube チャンネルへ動画を投稿するために作った、小さな自動投稿ツールです。一般の方向けのサービスではなく、作者本人だけが使います。

- 用途: 作者本人のチャンネルへ、動画を決まった日時に投稿します。
- 利用者: 作者本人のみ。
- プライバシーポリシー: [privacy.md](./privacy.md)

yt-upload is a small personal tool for uploading videos to the author's own YouTube channels. It is not a public service and is used only by its author.
